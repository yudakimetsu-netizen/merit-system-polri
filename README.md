# REST API Sistem Merit Personel Polri

Prototype aplikasi REST API untuk pengelolaan data kualifikasi dan riwayat jabatan personel Polri. Dibangun dengan Node.js, Express, Prisma, dan SQLite.

## 🛠️ Teknologi
- Node.js + Express
- Prisma ORM
- SQLite (Database)
- JWT (Autentikasi)
- Zod (Validasi Input)
